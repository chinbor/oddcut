# odd 日常碎片 · 拍摄清单

> 竖屏、主体居中、每段 3～8 秒稳住拍。一共拍 25～40 段，覆盖下面 5 类镜头，剪出来约 18 秒、16～20 个镜头。

## 一、手机设置

| 项目 | 怎么做 | 为什么 |
|---|---|---|
| 画幅 | 竖屏拍，主体放在画面中间 3/4 的区域内 | 成片是 3:4，会裁掉 9:16 画面的上下各约 1/8 |
| 分辨率 / 帧率 | 1080p 或 4K，30fps 或 60fps；不要用 24fps | 60fps 能做慢动作，24fps 在快切里显得卡 |
| 曝光 | 长按屏幕锁定曝光和对焦，曝光调到 -0.3 到 -0.7 | 风格偏暗调，暗部好调，过曝的天空救不回来 |
| 滤镜 | 关掉美颜、滤镜和画面上的水印文字 | 调色统一交给后期 |
| 变焦 | 不要用数码变焦，想拍近就走过去或切长焦镜头 | 数码变焦再加上 3:4 裁切，画质会明显变差 |
| 镜头 | 拍之前擦干净镜头 | 逆光镜头多，指纹会让画面发雾 |

## 二、镜头清单（共 25～40 段，每段 3～8 秒）

### ☐ 锚点镜头：1～2 段，每段 8～15 秒
- **用途**：开头 + 结尾（首尾呼应）
- **拍什么**：天空、地标、落叶、一条有特点的街道
- 同一个场景连续拍 8 秒以上，后期拆成前后两段
- 也可以拍同一个物体的两种状态：地上的落叶 → 手里捏着的落叶

### ☐ 手入镜：8～12 段，每段 3～6 秒，约占 30%
- **用途**：主体快切，风格最核心的镜头
- **拍什么**：手拿咖啡/奶茶、捏一片叶子、拿周边/票根、翻书、手摸宠物
- 物体每次都放在画面同一个位置（比如正中间），方便做匹配剪辑
- 如果有品牌产品，多角度拍 3 段以上，方便做抠图贴纸

### ☐ 动物：4～6 段，每段 3～8 秒，约占 15%
- **用途**：加 💢 / 问号涂鸦的主要载体
- **拍什么**：猫狗走过、回头、趴着、街头的流浪猫
- 在动物头顶上方留出一些空间，方便放涂鸦
- 动作发生时稳住 2 秒以上，贴纸跟踪才稳

### ☐ 光影：4～6 段，每段 4～8 秒，约占 15%
- **用途**：2～3 秒的呼吸镜头，给快节奏留出停顿
- **拍什么**：逆光树叶、墙上树影、夕阳、剪影、车窗/后视镜里的夕阳
- 可以暗，但要有明确的光源
- 尽量固定机位，让光影自己动

### ☐ 街景和店铺：8～12 段，每段 3～6 秒，约占 30%
- **用途**：交代地点、填充节奏
- **拍什么**：店招、小巷、路人、城市地标、店铺细节
- 一个场景拍远景、近景、细节几个角度
- 有行人或柱子从镜头前经过时别停，这是天然的遮挡转场

## 三、拍出 odd 感的技巧

**给拟人化留素材**
- 多拍正面朝向镜头的圆形物体：水果、杯子、球、路灯、车头、树冠（后期贴眼睛）
- 拍动物时头顶留空间（后期放 💢 / 问号）
- 主体稳定 2 秒以上

**为匹配剪辑做准备**
- 手拿的东西每次都放在画面同一个位置
- 选一个颜色贯穿整条视频（比如全片都是红色物体）
- 运动方向保持一致，比如都从左往右

**为遮挡转场做准备**
- 等行人、柱子、树干把画面完全挡住再离开，不要提前停

**首尾呼应**
- 锚点镜头拍 8 秒以上
- 开头和结尾可以是同一个物体的不同状态，循环播放时能接上

## 四、让自动剪辑剪得好

- 每段 3～8 秒，开始和结束各多拍 1 秒（会自动跳过首尾晃动，再在中间挑最好的 0.6～1.5 秒）
- 拍 25～40 段；素材太少时会重复使用同一段
- 稳住别甩，手抖的镜头会被自动过滤；走路拍时开防抖，或把手肘夹紧身体
- 可以暗但别全黑，夜景要有招牌、路灯、窗光这类光源
- 录到的现场声不影响，后期会换成音乐

## 五、常见翻车点

| 问题 | 结果 |
|---|---|
| 横屏拍 | 裁成 3:4 后只剩中间一窄条，画质变软 |
| 主体贴着画面边缘 | 裁切后主体被切掉 |
| 每段只拍 1 秒 | 没有余量挑选，切点不好卡 |
| 全是同一类镜头 | 节奏单调，颜色链也串不起来 |
| 自动曝光，在明暗之间来回跳 | 画面忽明忽暗，调色也压不住 |
