> 每条末尾约 3 秒是抖音平台自动加的片尾卡，不属于作品本身，下文时长都已扣除。

## 2. 共性（这就是"模板"要描述的东西）

### 2.1 结构与节奏
- **短**：正片 16～24 秒，20～30 个镜头，单镜 **0.6～1.5 秒**（中位数约 0.8 秒），偶尔一个 2～3 秒的"呼吸镜头"。
- **卡点**：剪辑点基本落在节拍/半拍上；快歌（150+ BPM）几乎全部卡拍，慢歌（76 BPM）切在半拍上。
- **纯音乐，无口播**：情绪全靠音乐和画面，没有解说字幕（v1 有歌词字幕）。
- **首尾呼应 / 循环**：5 条里 3 条首尾是同一场景（落叶、踢球、摩天轮），适合抖音循环播放。
- **开头 1 秒钩子**：第一镜就叠"系统 UI"（音乐播放卡、来电、控制中心），制造"这是我手机里的生活"的错觉。

### 2.2 素材（拍什么）
- **手机随手拍、第一人称**：大量"手入镜"——手拿杯子、手捏落叶、手拿唱片、手翻书。
- **日常碎片**：咖啡/奶茶、宠物和街头动物、街景、城市地标、店铺、食物。
- **光影镜头**：逆光树叶、墙上树影、夕阳、剪影——用来做节奏里的"呼吸"。
- **商业植入很自然**：v2 咖啡品牌、v3 沪上阿姨×Karry、v5 果汁品牌反复出镜。**这类风格本身就是品牌种草的载体，B 端价值很大。**

### 2.3 包装（"odd"感的核心来源）
| 手法 | 出现 | 本质 |
|---|---|---|
| 物体拟人：贴卡通眼睛 | v2 树、v3 公交、v5 水果 | 检测"圆形/有正面的物体"→贴眼睛→跟踪 |
| 手绘涂鸦符号：💢 ? ! 速度线 | v2 v4 v5（多用在动物头上） | 检测动物/人头部→贴符号→跟踪 |
| emoji 替换物体 | v2 足球、红绿灯 | 检测球/灯等→覆盖 emoji→跟踪 |
| 抠图白描边/撕纸边贴纸 | v3 奶茶、v5 果汁瓶 | 主体分割→加描边→定格弹出 |
| 系统 UI 叠加 | v1 v3 v4 | 固定素材动画（音乐卡、来电、控制中心、鼠标光标） |
| 超现实/名画合成 | v2 巨猫、v4 珍珠耳环 | AI 生成或换脸，难度最高 |
| 人物霓虹描边 | v3 | 人像分割→边缘发光 |
| 歌词逐字贴物体 | v1 | 歌词时间轴 + 摆放在物体旁 |

### 2.4 转场
1. **硬切卡点**（主力，占大多数）
2. **匹配剪辑**：上一镜手里的东西 → 下一镜同位置出现相似形状/颜色的东西（v3 最多，v5 用红色串联）
3. **前景遮挡转场**：行人/柱子扫过镜头时切换（v3）
4. **九宫格/窗格拼图转场**（v3 v5）
5. **撕纸转场**（v4 v5）、**白闪**（v2）

### 2.5 画面风格
- 画幅 **3:4**（720×960，或在 9:16 里上下加黑边）
- 偏暗、高对比、轻微暖色胶片感；底部居中小水印「ato」

## 3. 自动化难度评估

| 能力 | 难度 | 实现思路 |
|---|---|---|
| 卡点快切、3:4 画幅、调色 LUT、水印 | ★ | librosa 节拍 + FFmpeg |
| 首尾呼应 | ★ | 选一个素材，前半段做开头，后半段做结尾 |
| 系统 UI 叠加、白闪、九宫格、撕纸转场 | ★★ | 预制特效素材 / Remotion 组件 |
| 选镜：挑出好看的 0.6～1.5 秒片段 | ★★ | 多模态模型打分 + 运动/清晰度过滤 |
| 匹配剪辑 / 颜色贯穿的排序 | ★★★ | CLIP 向量 + 主色 + 主体位置相似度做镜头排序 |
| 眼睛/涂鸦/emoji 贴物体并跟踪 | ★★★ | 多模态模型决定"贴什么、贴哪儿"→ SAM2/YOLO 检测 + 跟踪 |
| 抠图描边贴纸、人物霓虹描边 | ★★★ | SAM2 / rembg 分割 + 描边 |
| AI 超现实合成、名画恶搞 | ★★★★ | 图像/视频生成 API，放后期 |

**结论**：做到 ★～★★ 能复刻 60% 的观感，加上 ★★★ 的"贴眼睛/涂鸦"才有灵魂——这是这个风格最有辨识度、也是你产品最该打磨的点。

## 4. 合规提醒
- 风格可以借鉴，但不要使用 Ato 的水印、原素材、原配乐；模板名不要直接用创作者名字。
- 音乐需走正版曲库或让用户自选平台音乐。
