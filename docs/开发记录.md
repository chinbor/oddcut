# 开发记录

每次工作结束都更新这份：改「现在做到哪」「下一步」，在「提交记录」末尾加一行。规则见 [AGENTS.md](../AGENTS.md)。

## 现在做到哪（2026-10-18）

- 编辑器已经是剪映式：主轨居中、画中画在上（用到才出现）、音乐在底部；拖边裁剪、吸附、撤销、可调时间线高度。
- 成片后可以导入新视频、图片、音乐，拖进主轨插入或拖到上方做画中画；Delete 删片段后主轨自动合拢；把歌拖到音乐轨就是换音乐。
- 抠像：智能点选（MobileSAM）、钢笔圈选、添加 / 擦除、描边。关键帧按钮在播放键旁边。
- 自动特效（万物生长、手绘、贴纸）都做了，按用户要求暂停。
- GitHub（https://github.com/chinbor/oddcut）停在 v0.4.1（c0e5fee），之后的提交都只在本地，等用户说推再推。

## 下一步

- 找几个朋友用他们自己的相册试用，收集问题。
- 已知问题：成片码率约 81 Mbps（18 秒约 180 MB），改成 CRF 18–20 需要用户同意，而且会改变老渲染的 framemd5。
- 暂缓：热点抓取、方案生成、自动收集素材、云端视觉接口（Agnes / 智谱，已测通，见设计文档）。
